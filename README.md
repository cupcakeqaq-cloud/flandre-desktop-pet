## 三、使用说明

### 3.1 启动

1. 下载后**解压整个文件夹**。
2. 双击 **`芙兰朵露.exe`**，芙兰就会出现在任务栏上方，正常情况任务栏托盘会出现芙兰小图标。
   ~~双击后没反应或者启动后托盘未出现图标就是bug了，对不起我不会修~~

> ⚠️ `芙兰朵露.exe` 必须和 `_internal\`、`贴图\`、`data\` 这几个文件夹待在**同一个目录**里。单独把 exe 拷到别处会打不开。

### 3.2 首次启动被 Windows 拦了？

程序没有代码签名证书，Windows SmartScreen 可能会提示"已保护你的电脑"，这是**正常现象**：

- 点「**更多信息**」→「**仍要运行**」即可。
- 如果没用试试右键**以管理员身份运行**目录里的 `关闭SmartScreen拦截(右键管理员运行).bat`，它会关掉整台机器的"检查应用和文件"选项（**会影响所有未签名程序的防护，安全性下降，请自己权衡**；之后可以在 Windows 安全中心重新打开）。

### 3.3 日常操作

| 操作              | 结果                                 |
| --------------- | ---------------------------------- |
| **左键点她**        | 随机说一句话（有概率是闲聊或季节问候；约 15% 概率弹出选项对话） |
| **右键点她**        | 弹出功能菜单                             |
| **按住左键拖动**      | 拎起芙兰                               |
| **拎起来甩一下松手**    | 她会飞出去然后很可怜的摔下来                     |
| **拖到任务栏下面**     | 会自动弹回来                             |
| **把文件拖到她身上**    | 「赠礼」：文件会被**移动**到 `收藏\` 文件夹里        |
| **放着不管 15 分钟**  | 坐下休息，点击进行交互就会起来                    |
| **双击托盘图标**      | 显示 / 隐藏芙兰                          |
| **托盘图标右键 → 退出** | 完全关掉程序~~（其实直接右键芙兰菜单里面也有退出）~~       |

> 右键菜单里有：隐藏、番茄钟、倒计时、倒数日、待办清单、打开收藏文件夹、设置、退出。

### 3.4 把她藏起来了怎么找回来

右下角（或你原本的托盘位置）有个**芙兰的图标**，**双击**就回来了；右键它也能选显示或退出。

### 3.5 设置里能改什么

右键 →「设置」：

- **怎么称呼你**：改了之后所有台词里的称呼立刻跟着变（默认是"你"）。
- **气泡时长**：一句话停留几秒。
- **倒计时每秒刷新气泡**：省性能用的开关。
- **界面字体**：切换到系统字体需要重启程序。
- **类型管理**：自定义番茄钟的任务类型、倒数日的事件类型（各最多 3 个）。

### 3.6 自带功能一览

- **番茄钟**：可设置专注 / 休息时长、循环次数、长休息，任务类型可自定义。
- **倒计时**：任意时长，到点提醒。
- **倒数日**：设置事件名称 + 类型 + 日期，她会**按类型说不一样的话**（考试、约会、见面、面试、纪念日、生日，或你自己加的类型）。
- **待办清单**：独立窗口，可增删、可勾选完成、双击可改内容；**勾掉的任务不会自动消失**，要清掉得按「清除已完成」（会二次确认）或「删除选中」。
- **整点报时**：每个整点都会报时并随机换一句问候（分凌晨 / 上午 / 午后 / 傍晚 / 深夜）。
- **季节问候**：按春夏秋冬 + 下雨随机插一句问候。
- **赠礼**：拖文件给她 → 收进 `收藏\`，单次拖放总量上限 **100 MiB（约 104.9 MB）**；文件夹也行。

### 3.7 数据都存在哪

全部在程序目录里，**不上传、不联网**：

| 路径                    | 内容                    |

| `收藏\`                 | 拖给她的文件都移动到这里          |

**想搬家 / 备份**：把整个文件夹拷走就行。

## 四、魔改 / 二改教程

### 4.1 贴图对应表 + 怎么改

所有贴图都在 `贴图\` 目录下，**文件名就是它的用途，别改名字**：

| 文件                    | 什么时候用                                        |
| --------------------- | -------------------------------------------- |
| `贴图\站立\1.png`         | 常规站着、不说话                                     |
| `贴图\站立\2.png`         | 说话时（张嘴帧）                                     |
| `贴图\站立\3.png`         | **生气脸**：被拖到任务栏、摔到地上爬起来、选到让她不爽的选项             |
| `贴图\站立\4.png`         | **开心脸**：收到赠礼、任务完成                            |
| `贴图\奔跑\1.png` `2.png` | 奔跑的两帧循环（**走路也复用这两帧**，只是切得慢一些）。默认朝左，朝右时程序自动镜像 |
| `贴图\拎起\1.png` `2.png` | 被拎起来挣扎的两帧（拎起瞬间是 1，1 秒后切 2）                   |
| `贴图\拎起\3.png`         | 松手后开始下坠的第一帧                                  |
| `贴图\拎起\4.png`         | 快碰到任务栏时换这一帧                                  |
| `贴图\拎起\5.png`         | 摔到任务栏上（落地），会保持 2 秒再爬起来                       |
| `贴图\休息\1.png`         | 休息被戳醒                                        |
| `贴图\休息\2.png`         | 闭眼休息                                         |
| `贴图\icon.ico`         | 托盘图标（也是 exe 图标），想换图标就换它                      |
| `贴图\icon.png`         | 只是留着的原图，程序没用它，改不改都行                          |

> `奔跑\1、2` 和 `拎起\3、4、5` 这几张**默认朝左**：如果她向右跑 / 向右被甩出去，程序会自动水平镜像。所以画的时候**全部朝左画**就行。

**怎么改？**

1. **文件名、目录名、扩展名一个都别改**（程序就是按这些名字去读的），直接**覆盖同名文件**。
2. 建议规格：**1000 × 1000、正方形、PNG、透明背景**（现有贴图都是这个规格）。程序会把它缩到 240 像素显示。
   - 换成别的尺寸也能跑，但会被**拉成正方形**，所以尽量保持正方形比例。
3. **透明背景很重要**：只有不透明的像素才能被鼠标点到。画布上多余的不透明区域会让"点得到"的范围变大。
4. **脚底对齐**：`站立\1~4.png` 和 `休息\1~2.png` 的脚底现在都尽量压在贴图**最底边**上，这 6 张尽量一起对齐，否则换帧、以及从休息站起来的时候人会悬浮/上下跳。`拎起\`、`奔跑\` 那几张各自独立，不需要和站立对齐。
   可以参考自带的贴图比对高度。
5. 画完以后存成 **PNG** 透明底图片文件，如果有白底就是你导出有问题，检查一下文件格式或者绘画文件的白底图层有没有隐藏 / 导出的时候有没有勾选导出透明底。
6. 改完**不用重新打包程序**，直接重启 `芙兰朵露.exe` 就生效。

> 想让她整体变大变小？那是代码里的参数（`src\config.py` 的 `DISPLAY_SIZE`），改代码需要重新打包，见 4.4。

### 4.2 台词魔改

#### 4.2.1 台词文件在哪

`data\dialogue.json`——**全部台词都在这一个文件里**，纯文本，用记事本或 VS Code 打开就能改。

结构很简单：**每个分类是一个字符串数组，程序每次从这个数组里随机抽一条。**

```json
{
  "click": [
    "嗯？{nickname}叫我？",
    "干嘛呀。",
    "唔……什么事？"
  ]
}
```

**想加台词就加一行，想删就删掉那一行**（记得保持 JSON 语法正确：字符串之间要有逗号，最后一行后面**不要**逗号）。

#### 4.2.2 分类 → 触发时机对照表

改台词之前先看这张表，找到你想改的那句是"在什么情况下说出来的"：

| 分类                                                                | 什么时候会用到                               |
| ----------------------------------------------------------------- | ------------------------------------- |
| `click`                                                           | 站着的时候被左键点（默认的短应答）                     |
| `click_annoy`                                                     | **3 秒内连点 5 下**，她会生气（同时切 `站立\3.png`）   |
| `idle_talk`                                                       | 主动闲聊（左键时有 25% 概率、以及定时 40~120 秒自己冒一句时） |
| `choices`                                                         | **带选项的对话**（左键时约 15% 概率出现），结构见 4.2.4   |
| `running`                                                         | 开始奔跑时                                 |
| `running_click`                                                   | 奔跑途中被点                                |
| `rest_wake`                                                       | 休息时被戳醒（不满）                            |
| `struggle`                                                        | 被拎起来挣扎时                               |
| `falling`                                                         | 松手后往下掉的时候                             |
| `fallen`                                                          | 摔到地上爬起来时（同时生气脸）                       |

| `pomodoro_break_end`                                              | 一轮休息结束、该继续了                           |

| `countdown_day`                                                   | 倒数日（没有专属类型时的兜底）                       |
| `countdown_day_exam`                                              | 事件类型是「考试」                             |

| `countdown_day_interview`                                         | 「面试」                                  |

#### 4.2.3 台词里的三个占位符

| 占位符          | 会替换成                     |
| ------------ | ------------------------ |
| `{nickname}` | 设置里填的**称呼**（默认"你"）       |
| `{name}`     | 倒数日的**事件名称**（只有倒数日的分类能用） |
| `{days}`     | **还剩几天**（只有倒数日的分类能用）     |

例：`"{nickname}，考试还有{days}天，别慌哦。"`

> **硬规则：台词里不要写死"你"**，称呼一律写 `{nickname}`。
> 否则改了称呼之后，那句话还是喊"你"，会很出戏。

#### 4.2.4 选项对话（`choices`）怎么写

`choices` 是数组里套对象，每条长这样：

```json
{
  "line": "唔……好无聊！我们一起玩呀？",
  "options": [
    { "label": "好啊，玩什么？", "reply": "诶嘿嘿！{nickname}猜……算了，我自己也忘了。" },
    { "label": "等一下，我在忙", "reply": "唔……那{nickname}忙吧，快点哦。", "mood": "angry" }
  ]
}
```

- `line`：她问的那句话。
- `options`：按钮，2~3 个都行。
- `label`：按钮上的字。
- `reply`：**你选了这个之后她的反应**（就是"改触发反应"最直接的地方——想让她在被拒绝时说的话变温柔一点，改 `reply` 就行）。
- `mood`（可省略）：选完后她的表情。
  - `"mood": "angry"` → 生气脸（`站立\3.png`）
  - `"mood": "happy"` → 开心脸（`站立\4.png`）
  - **不写** → 普通表情
  - 表情只在站着的时候生效，持续时间和气泡一样长。

#### 4.2.5 改台词的注意事项

1. **编码必须是 UTF-8，而且千万不要存成"UTF-8 with BOM"**。带 BOM 会让程序读不出台词文件（而且不会报错，所以要特别注意）。记事本另存为时注意选「UTF-8」而不是「UTF-8 with BOM」。
2. **JSON 语法要正确**：字符串用双引号、条目之间用逗号、最后一条**不能**有逗号。写完丢进任意在线 JSON 校验器点一下最稳。
3. **改完不用重新打包**，重启 `芙兰朵露.exe` 就生效。
4. 别删掉整个分类。真的删了程序只是在那句话该出现的时候找不到内容，触发对话时会沉默。

- 上面前两处是 `.py` 文件，**改完必须重新打包才生效**（见 4.4）；只改台词的话重启程序就行。
- 换完角色之后如果要公开发布，第八节的二创声明也得跟着改：换成别的**东方**角色，版权声明照样写给 ZUN；换成别的作品的角色，就**不能再自称「东方Project 二创」**了，出处得你自己写清楚。

### 4.4 改代码 / 重新打包

- 源码在 `src\` 里（Python 3.12 + PySide6 + Pillow，用 PyInstaller 按 onedir 方式打包）。
- **改 `.py` 文件必须重新打包才能生效**；改 `data\dialogue.json` 和 `贴图\` 里的图片则不用，重启程序就行。
- 打包大致流程：装好依赖 → `pyinstaller` 用 onedir 模式打 `src\main.py` → 把 `贴图\`、`data\`、`font\`、`sound\` 一起放到输出目录里 → 打包出来的 exe 必须和 `_internal\` 同目录。
- 常见坑：图标要用 `贴图\icon.ico`；`font\` 里的思源黑体要用上就得一起带上；Qt 插件缺了会直接起不来（PyInstaller 的 PySide6 hook 会自动收集，但精简过头就会漏）。
- 改完记得把 exe 文件名、readme 里的版本号一起更新一下。

### Q4：为什么点她有时候没反应？

**A：** 她在**奔跑**或者**走路**的时候不一定会理你，打盹的时候戳一下倒是会醒。总之跑步不理你那就等她停下来再点。

### Q5：我改了台词 / 贴图，为什么没生效？

**A：** 确认一下有没有完全修改**程序目录下**的文件？确认后**重启程序**即可（这两类文件都不用重新打包）。另外台词文件存成 BOM 编码会静默失效，见 4.2.5。

### Q6：拖动文件给芙兰后我的文件就消失了！她把我的文件弄哪去了？

**A：** 拖给她的文件是**移动**（不是复制）到程序目录的 `收藏\` 里。移动失败会自动回滚，不会出现"源文件和收藏里各有一份"的情况，具体原因记在 `data\gift.log`。

**所以右键芙兰打开收藏文件夹或者直接去文件目录翻就行了。**

### Q7：她会不会联网、会不会偷看我电脑？

**A：** 不会。程序没有任何联网代码，数据全部存在程序目录里，删掉文件夹就干干净净。

### Q8：支持 Mac / 手机吗？

**A：** 目前只支持 Windows。

### Q9：想让芙兰休息得频繁一点 / 别老打盹？

**A：** 打盹间隔是代码里的固定值（15 分钟），改它需要改 `src\config.py` 并重新打包。
