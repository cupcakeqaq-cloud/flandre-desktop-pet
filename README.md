## 三、使用说明

> 先说三个"新功能"。**这三个默认全都是关的**，不开也完全能玩——离线时台词语音之外的一切跟以前一模一样。

### 3.1 语音输入（按住说话键说话）★

**这是什么**：按住一个键说一句话，松开之后她把你说的话**在本机认成文字**，显示在气泡里，然后回你一句。

**怎么开**：

1. 右键 →「设置」→ 找到「语音」那张卡。
2. 勾上「**按住说话键说话**」。默认说话键是 **F8**。
3. 想换键：点一下说话键那个输入框，然后按下你想用的键（单个键、或者 `Ctrl+Shift+Q` 这种组合都行）。**强烈建议换一个不常用的键**，原因见下面"已知问题"。
4. 取消勾选就是彻底关掉，关掉之后**连录音都不会开始**。

**怎么用**：

- 按住说话键（默认 F8），说话，**说完再松手**。她头顶会转一会儿圈圈（认字中），认完字会冒出气泡。
- 按一下马上松手（不到 0.6 秒）算误触，她不理你——不会为了误触弹气泡。
- 按住超过 60 秒会自动截断。
- 松开之后最多等 20 秒，还没结果就说一句"没听清"（60 秒内只念一次，不烦你）。
- 录音的临时文件认完字**立刻删**，不会留在 `data\` 里。

**它到底联不联网、花不花钱**：

- 用的是程序**自带的本机离线识别模型**（在 `model\asr\` 里，占了发布包一大半体积就是它）。**不联网、不花钱、不上传任何东西。**
- ⚠️ **别删 `model\` 文件夹**，删了语音就直接没有。也别在 Windows 隐私设置里关掉"允许桌面应用访问麦克风"。

**已知问题（真的很重要，不是你的错觉）**：

1. **经常认错字。** 本地跑的小模型，准确率就那样：口音重、环境吵、语速快、连读，都容易错。
2. **什么都没说，也可能被录成一句字**（键盘声、咳嗽、环境噪音偶尔被当成语音）。
3. **按住热键没反应，这个非常常见。** 原因基本都是**热键冲突 / 输入法抢键**：后台的输入法、游戏、录屏软件、聊天软件、快捷键工具都可能把 F8 之类抢走。解决办法：**在设置里把说话键换成一个不容易撞的组合**（比如 `Ctrl+Alt+Y` 这种），或者先把后台占键的程序关掉试试。
4. **作者的原话总结**：*准确率比较差，但是模型能脑补、并且会自己更正句子，所以语音交流大部分情况没问题；也有什么都没说就被录成文字、以及热键失灵的情况。目前不算很实用的功能，只能等后续优化。*

> 至于"说完不回答"“太久没反应"——那是上面第 2 条（听错了）或者 20 秒兜底在起作用，不是另开一个 bug。

### 3.2 在线模式（让芙兰现编台词 / 打字聊天）★

**这是什么**：接一个你自己的大模型 API（OpenAI 兼容的那种），开了之后两件事变了：

- **点她一下，她不再从 `data\dialogue.json` 里抽，而是现场编一句**（会结合人设和你这会儿在干什么）。
- 右键菜单最上面多一项「**聊天**」，能打字跟她聊。

**不开也完全没事**，离线那句句都是写好的台词，该有的功能一个不少。

**怎么开（三步）**：

1. 右键 →「设置」→ 找到「对话模型」。
2. 填**接口地址**、**API key**、**模型名**三栏——三样填齐了，"启用在线模式"会**自动勾上**（想回离线就手动取消勾）。
3. 点「**测试连接**」：通了会提示成功；报错的话看下面"出问题先看这里"。

**地址不用写全**，填到域名就行，程序会自动补 `/chat/completions`（末尾多打的 `/` 也能认）：

| 服务 | 接口地址填这个 | 模型名填这个 | key 去哪弄 |
| --- | --- | --- | --- |
| **DeepSeek** | `https://api.deepseek.com` | `deepseek-chat` | `platform.deepseek.com` 注册 →「API keys」→ 新建 → 复制那串 `sk-...`（**只显示一次，丢了就再建一个**） |
| **硅基流动 SiliconFlow** | `https://api.siliconflow.cn/v1` | 网站上那个完整名字，例如 `deepseek-ai/DeepSeek-V3` | `cloud.siliconflow.cn` 注册 →「API 密钥」→ 新建 |
| **本机 Ollama**（不花钱） | `http://127.0.0.1:11434/v1` | `ollama list` 里看到的那个名字，例如 `qwen2.5:7b` | 本机不用 key，但**这一栏不能空**，随便填一个字（比如 `x`），否则程序当成没填 |
| **别的中转站 / 自建** | 它给你的地址（常见 `https://xxx/v1`） | 它给你的模型名 | 它给你的 key |

> 用 DeepSeek 的话，注册后在「充值」里充最小额度再用（国内平台一般支持支付宝/微信）；它家新账号有时会送一点体验额度。
>
> 温度默认 `0.9`。**别调到 1.5 以上**——程序封顶也是 1.5，再高这个模型就开始整段胡言乱语了。

**多少会花钱**：她说的每一句都是一次 API 调用——你点她一下、她自己凑过来搭一句、你在聊天窗里发一句，都算一次。

- 她自己凑过来的话有**冷却**（默认 10 分钟才一次）和**每日上限**（默认 **100 条**）。
- 点她 + 她自己说话**合计**每天默认最多 100 次。
- **聊天窗里你打的字不占这个名额**，但一样是花钱的调用。
- 想省钱：把每日上限调小、或者干脆只在想聊的时候开一下。

**出问题了先看这里**：

1. 「测试连接」通不通？报 **401 / 403** = key 填错了或过期；**402** = 账户余额不够；**429** = 问得太勤，等会儿再试；**其他连不上** = 地址打错了（少了 `/v1`、多了空格、填成网页地址都不行），或者被网络 / 代理挡了。
2. 点她没反应但也不报错 → 每日名额用完了 / 还在冷却，或者上一个请求还没回来。
3. 出错时她会说一句「唉……电波貌似接收失败了，{nickname}去检查一下吧？」，同时 `sound\error.wav` 响一声（60 秒内只响一次，不会连续吵你）。
4. 想在不花钱的情况下试试界面：设置一个环境变量 `FLANDRE_LLM_MOCK=1` 再启动，请求会被假的回复顶掉（**这只是给开发测试用的**，正常玩别设）。

> API key 会**明文**存在 `data\settings.json` 里，就像个记事本；**别把这个文件发给别人**，也别截图发出来。
> 发布包里**不含** `settings.json`，所以别人解压下来是干净的、没有你的 key。

### 3.3 芙兰看见你在干什么（桌面感知）★

**这是什么**：她会偶尔瞄一眼你**正在用什么程序**，然后凑过来说一句（打游戏就吵着要一起玩、写文档就念叨你别一直不停、连着忙太久就催你歇会儿）。

**怎么开**：右键 →「设置」→「芙兰看见你在干什么」→ 勾「**可以主动来搭话**」。

那张卡里还能调：

- **同类冷却**（默认 600 秒）：同一个程序，这么多秒内最多搭一次话。
- **每日上限**（默认 100 条）：跟 3.2 的每日上限是同一本账。
- **全屏时自动躲起来**（默认开）：你全屏（打游戏、看视频）她就先躲到看不见，退出全屏再回来。见下面的全屏说明。

**它到底看什么（重点）**：

- **只读窗口标题和程序名**（标题最多截 60 个字），**不截图、不录屏、不看画面内容、不读文件、不碰键盘记录**。
- 这些文字**只有开了在线模式时**才会跟着请求发给你自己填的那个 API 地址；离线状态下一个字都不外发。
- 全屏躲起来的时候，她连请求都不发。

**几个注意事项**：

- **这个功能要靠在线模式才有话**。只开「看见你在干什么」、不填 API，她没东西可编，点她会弹"电波接收失败"那种报错。所以正确的顺序是：先按 3.2 把在线模式弄通，再回来开这个。
- **连续工作催休息**：连着有键鼠输入满 **50 分钟**才催一次，同类冷却 30 分钟。这条**不受每日上限限制**（真熬太久就该被念）。
- **"你回来了"**：你离开超过 5 分钟再回来，她会说一句"你可算回来了"，一小时最多一次。
- 采样是后台每隔几秒读一次前台窗口，几乎不占性能。

**全屏躲起来怎么算**：

- 前台窗口一全屏，她就自动隐藏；退出全屏自己回来。
- 如果她正在躲着，你**从托盘手动点了显示**，那**这一次全屏期间她就不再躲了**（这个设计是为了防止你跟别人全屏通话时她突然消失又出现刷屏）。
- 不想让她躲：设置里取消勾「全屏时自动躲起来」。

> 想快速试这个功能：先在 3.2 把在线模式弄通，再勾上「可以主动来搭话」，然后把同类冷却调到最小（1 秒左右）、随便切几个程序，几十秒内她就会开始念你在干什么。

| **按住左键拖动**      | 拎起芙兰                               |
| **拎起来甩一下松手**    | 她会飞出去然后很可怜的摔下来                     |
| **拖到任务栏下面**     | 会自动弹回来                             |
| **把文件拖到她身上**    | 「赠礼」：文件会被**移动**到 `收藏\` 文件夹里        |
| **放着不管 15 分钟**  | 坐下休息，点击进行交互就会起来                    |
| **双击托盘图标**      | 显示 / 隐藏芙兰                          |
| **按住说话键说话**     | 语音输入（默认 F8，见 3.1，默认关）              |
| **右键 → 聊天**     | 打字跟她聊（**只有开了在线模式才有这一项**，见 3.2）     |

> 开了在线模式之后，菜单最上面会多一项「聊天」。

### 3.7 把她藏起来了怎么找回来

右下角（或你原本的托盘位置）有个**芙兰的图标**，**双击**就回来了；右键它也能选显示或退出。

### 3.8 设置里能改什么

右键 →「设置」：

- **怎么称呼你**：改了之后所有台词里的称呼立刻跟着变（默认是"你"）。
- **气泡时长**：一句话停留几秒。
- **倒计时每秒刷新气泡**：省性能用的开关。
- **界面字体**：切换到系统字体需要重启程序。
- **对话模型（在线模式）**：填接口地址 / API key / 模型名，开了才会现编台词、才有「聊天」。见 3.2。
- **芙兰看见你在干什么**：让她偷偷瞄你在用什么程序（**只读窗口标题和程序名，不截图**），偶尔凑过来说一句；还能设冷却、每日上限、全屏时自动躲起来。见 3.3。
- **语音**：按住说话键说话，松开转成字气泡里显示。认字用的是程序自带的**本机离线模型**，不联网、不花钱。见 3.1。
- **类型管理**：自定义番茄钟的任务类型、倒数日的事件类型（各最多 3 个）。

### 3.9 自带功能一览

- **番茄钟**：可设置专注 / 休息时长、循环次数、长休息，任务类型可自定义。
- **倒计时**：任意时长，到点提醒。
- **倒数日**：设置事件名称 + 类型 + 日期，她会**按类型说不一样的话**（考试、约会、见面、面试、纪念日、生日，或你自己加的类型）。
- **待办清单**：独立窗口，可增删、可勾选完成、双击可改内容；**勾掉的任务不会自动消失**，要清掉得按「清除已完成」（会二次确认）或「删除选中」。
- **整点报时**：每个整点都会报时并随机换一句问候（分凌晨 / 上午 / 午后 / 傍晚 / 深夜）。
- **季节问候**：按春夏秋冬 + 下雨随机插一句问候。
- **赠礼**：拖文件给她 → 收进 `收藏\`，单次拖放总量上限 **100 MiB（约 104.9 MB）**；文件夹也行。
- **在线模式（可选）**：开了之后点她会现编台词、右键能打字聊天。**默认是关的**，不填也没关系，离线该有的功能一个不少。见 3.2。
- **语音输入（可选）**：按住说话键说话，本机认字。**默认是关的**，见 3.1。
- **桌面感知（可选）**：看见你在干什么，偶尔搭一句、催你休息。**默认是关的**，见 3.3。

### 3.10 数据都存在哪

全部在程序自己这个目录里：

| 路径                     | 内容                    |
| ---------------------- | --------------------- |
| `data\settings.json`   | 你的设置（称呼、气泡时长、自定义类型、API key……） |
| `data\dialogue.json`   | **全部台词**，可以随便改        |
| `data\chat_history.json` | 在线模式的聊天记录（**每次启动自动清空**） |
| `data\todos.json`      | 待办列表                  |
| `data\countdown.json`  | 倒数日列表                 |
| `data\gift.log`        | 赠礼拖放的诊断日志（拖文件失败时看这个）  |
| `收藏\`                  | 拖给她的文件都移动到这里          |

**想搬家 / 备份**：把整个文件夹拷走就行。

> 她只会待在**主显示器**上，多屏的话不会跑去副屏。
>
> 数据不会上传到任何地方。唯一的例外是你自己开了在线模式（见 3.2）/ 桌面感知（见 3.3）：那时候会连**你自己填的** API 地址，把当前这几句对话发过去，感知还会带上窗口标题和程序名（不截图）。
>
> API key 是**明文**存在 `data\settings.json` 里的（就是个本地文本文件，别把这个文件发给别人）。**发布包里不含 `settings.json`**，所以别人解压下来是干净的、没有你的 key。
> 语音只在**按住说话键的时候**才录音，录出来的临时文件认完字就删了。

### 4.1 贴图对应表 + 怎么改

所有贴图都在 `贴图\` 目录下，**文件名就是它的用途，别改名字**：

| 文件                    | 什么时候用                                        |
| --------------------- | -------------------------------------------- |
| `贴图\站立\1.png`         | 常规站着、不说话                                     |

| `贴图\站立\4.png`         | **开心脸**：收到赠礼、任务完成                            |
| `贴图\奔跑\1.png` `2.png` | 奔跑的两帧循环（**走路也复用这两帧**，只是切得慢一些）。默认朝左，朝右时程序自动镜像 |
| `贴图\拎起\1.png` `2.png` | 被拎起来挣扎的两帧（拎起瞬间是 1，1 秒后切 2）                   |
| `贴图\拎起\3.png`         | 松手后开始下坠的第一帧                                  |
| `贴图\拎起\4.png`         | 快碰到任务栏时换这一帧                                  |
| `贴图\拎起\5.png`         | 摔到任务栏上（落地），会保持 2 秒再爬起来                       |
| `贴图\休息\1.png`         | 休息被戳醒                                        |
| `贴图\休息\2.png`         | 闭眼休息                                         |
| `贴图\icon.ico`         | 托盘图标（也是 exe 图标），想换图标就换它                      |
| `贴图\icon.png`         | 只是留着的原图，程序没用它，改不改都行                          |

> `奔跑\1、2` 和 `拎起\3、4、5` 这几张**默认朝左**：如果她向右跑 / 向右被甩出去，程序会自动水平镜像。所以画的时候**全部朝左画**就行。

**怎么改？**

1. **文件名、目录名、扩展名一个都别改**（程序就是按这些名字去读的），直接**覆盖同名文件**。
2. 建议规格：**1000 × 1000、正方形、PNG、透明背景**（现有贴图都是这个规格）。程序会把它缩到 240 像素显示。
   - 换成别的尺寸也能跑，但会被**拉成正方形**，所以尽量保持正方形比例。
3. **透明背景很重要**：只有不透明的像素才能被鼠标点到。画布上多余的不透明区域会让"点得到"的范围变大。
4. **脚底对齐**：`站立\1~4.png` 和 `休息\1~2.png` 的脚底现在都尽量压在贴图**最底边**上，这 6 张尽量一起对齐，否则换帧、以及从休息站起来的时候人会悬浮/上下跳。`拎起\`、`奔跑\` 那几张各自独立，不需要和站立对齐。
   可以参考自带的贴图比对高度。
5. 画完以后存成 **PNG** 透明底图片文件，如果有白底就是你导出有问题，检查一下文件格式或者绘画文件的白底图层有没有隐藏 / 导出的时候有没有勾选导出透明底。
6. 改完**不用重新打包程序**，直接重启 `芙兰朵露.exe` 就生效。

> 想让她整体变大变小？那是代码里的参数（`src\config.py` 的 `DISPLAY_SIZE`），改代码需要重新打包，见 4.4。
>
> 注意：**改贴图玩没问题，但把改完的图拿去商用要先看 `LICENSE-贴图`**——原版贴图本身不许商用，你要是整张重画的那就是你自己的作品了。

### 4.2 台词魔改

#### 4.2.1 台词文件在哪

`data\dialogue.json`——**全部台词都在这一个文件里**，纯文本，用记事本或 VS Code 打开就能改。

结构很简单：**每个分类是一个字符串数组，程序每次从这个数组里随机抽一条。**

```json
{
  "click": [
    "嗯？{nickname}叫我？",
    "干嘛呀。",
    "唔……什么事？"
  ]
}
```

**想加台词就加一行，想删就删掉那一行**（记得保持 JSON 语法正确：字符串之间要有逗号，最后一行后面**不要**逗号）。

#### 4.2.2 分类 → 触发时机对照表

改台词之前先看这张表，找到你想改的那句是"在什么情况下说出来的"：

| 分类                                                                | 什么时候会用到                               |
| ----------------------------------------------------------------- | ------------------------------------- |
| `click`                                                           | 站着的时候被左键点（默认的短应答）                     |
| `click_annoy`                                                     | **3 秒内连点 5 下**，她会生气（同时切 `站立\3.png`）   |
| `idle_talk`                                                       | 主动闲聊（左键时有 25% 概率、以及定时 40~120 秒自己冒一句时） |
| `choices`                                                         | **带选项的对话**（左键时约 15% 概率出现），结构见 4.2.4   |
| `running`                                                         | 开始奔跑时                                 |
| `running_click`                                                   | 奔跑途中被点                                |
| `rest_wake`                                                       | 休息时被戳醒（不满）                            |
| `struggle`                                                        | 被拎起来挣扎时                               |
| `falling`                                                         | 松手后往下掉的时候                             |
| `fallen`                                                          | 摔到地上爬起来时（同时生气脸）                       |
| `drag_down`                                                       | 被拖到任务栏下面（同时生气脸）                       |
| `gift`                                                            | 收到赠礼、成功收下（同时开心脸）                      |
| `gift_too_big`                                                    | 拖来的东西超过 100 MiB                       |
| `gift_fail`                                                       | 移动文件失败                                |
| `pomodoro_start` / `pomodoro_end`                                 | 番茄钟开始 / 一个专注时段结束                      |
| `pomodoro_break_end`                                              | 一轮休息结束、该继续了                           |
| `countdown_start` / `countdown_end`                               | 倒计时开始 / 归零                            |
| `countdown_day`                                                   | 倒数日（没有专属类型时的兜底）                       |
| `countdown_day_exam`                                              | 事件类型是「考试」                             |
| `countdown_day_date`                                              | 「约会」                                  |
| `countdown_day_meet`                                              | 「见面」                                  |
| `countdown_day_interview`                                         | 「面试」                                  |
| `countdown_day_anniversary`                                       | 「纪念日」                                 |
| `countdown_day_birthday`                                          | 「生日」                                  |
| `countdown_day_custom`                                            | 你自己加的自定义类型                            |
| `todo_done`                                                       | 待办勾选完成                                |
| `hourly_morning` / `_noon` / `_afternoon` / `_evening` / `_night` | 整点报时（按当前时段选）                          |
| `season_spring` / `_summer` / `_autumn` / `_winter`               | 季节问候（3-5 春 / 6-8 夏 / 9-11 秋 / 12-2 冬） |
| `season_rain`                                                     | 季节问候里抽到"下雨"（25% 概率）                   |

#### 4.2.3 台词里的三个占位符

| 占位符          | 会替换成                     |
| ------------ | ------------------------ |
| `{nickname}` | 设置里填的**称呼**（默认"你"）       |
| `{name}`     | 倒数日的**事件名称**（只有倒数日的分类能用） |
| `{days}`     | **还剩几天**（只有倒数日的分类能用）     |

例：`"{nickname}，考试还有{days}天，别慌哦。"`

> **硬规则：台词里不要写死"你"**，称呼一律写 `{nickname}`。
> 否则改了称呼之后，那句话还是喊"你"，会很出戏。

#### 4.2.4 选项对话（`choices`）怎么写

`choices` 是数组里套对象，每条长这样：

```json
{
  "line": "唔……好无聊！我们一起玩呀？",
  "options": [
    { "label": "好啊，玩什么？", "reply": "诶嘿嘿！{nickname}猜……算了，我自己也忘了。" },
    { "label": "等一下，我在忙", "reply": "唔……那{nickname}忙吧，快点哦。", "mood": "angry" }
  ]
}
```

- `line`：她问的那句话。
- `options`：按钮，2~3 个都行。
- `label`：按钮上的字。
- `reply`：**你选了这个之后她的反应**（就是"改触发反应"最直接的地方——想让她在被拒绝时说的话变温柔一点，改 `reply` 就行）。
- `mood`（可省略）：选完后她的表情。
  - `"mood": "angry"` → 生气脸（`站立\3.png`）
  - `"mood": "happy"` → 开心脸（`站立\4.png`）
  - **不写** → 普通表情
  - 表情只在站着的时候生效，持续时间和气泡一样长。

#### 4.2.5 改台词的注意事项

1. **编码必须是 UTF-8，而且千万不要存成"UTF-8 with BOM"**。带 BOM 会让程序读不出台词文件（而且不会报错，所以要特别注意）。记事本另存为时注意选「UTF-8」而不是「UTF-8 with BOM」。
2. **JSON 语法要正确**：字符串用双引号、条目之间用逗号、最后一条**不能**有逗号。写完丢进任意在线 JSON 校验器点一下最稳。
3. **改完不用重新打包**，重启 `芙兰朵露.exe` 就生效。
4. 别删掉整个分类。真的删了程序只是在那句话该出现的时候找不到内容，触发对话时会沉默。
5. **在线模式下 `click` 这些离线台词就不走了**（她改成现编）；想让她继续念你写的台词，就关掉在线模式。

### 4.3 改角色名字（人物魔改）

名字不是设置项，而是写在程序里的，一共 4 处：

| 位置                   | 是什么                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------- |
| `src\config.py:4`    | `APP_NAME = "芙兰朵露"`——托盘图标的悬停提示（`src\tray.py:14`）和程序内部名（`src\main.py:44`）都读它           |
| `src\bubble.py:42`   | `QLabel("芙兰朵露·斯卡蕾特")`——对话气泡顶上那行标题。**注意代码里写的是"斯卡蕾特"，和 readme 正文用的"斯卡雷特"不一样，改的时候别改错地方** |
| `data\dialogue.json` | 台词里直接喊到自己名字的句子（搜「芙兰」「芙兰朵露」），属于台词内容，只能一句句手动改                                           |
| 文件名                  | `芙兰朵露.exe`、`贴图\icon.ico`（托盘图标），想换就一起换                                                 |

### 4.4 改代码 / 重新打包

**仓库里有什么**（就这些，多余的都清掉了）：

| 路径 | 是什么 | 能改吗 |
| --- | --- | --- |
| `src\` | 全部 Python 源码（19 个 `.py`） | ✅ 随便改 |
| `data\` | 台词、待办、倒数日（`dialogue.json` 就是全部台词） | ✅ 随便改 |
| `贴图\` | 美术资源 | ✅ 按 4.1 换 |
| `font\`、`sound\` | 界面字体、音效 | ✅ 可换 |
| `model\asr\` | 本机离线语音识别模型 | ❌ **别删**，删了语音就没了 |
| `_internal\` | exe 的运行库（Qt / Python 运行时） | ❌ **别动**，和 exe 必须同目录 |
| `芙兰朵露.exe` | 打包好的程序 | 重打包会覆盖它 |

**改完 `.py` 怎么立刻看效果（不用打包）**：

```bat
.venv\Scripts\python.exe src\main.py
```

本地目录里有个现成的 `.venv`（Python 3.12 + PySide6 + Pillow + sherpa-onnx），直接跑就是源码版，改一行重启一次就能看，比打包快得多。`.venv` 不进仓库（太大），你自己 clone 下来没有的话装一遍就行：

```bat
python -m venv .venv
.venv\Scripts\pip install PySide6 Pillow sherpa-onnx numpy
```

**要重新打包成 exe 才生效的情况**：改 `src\` 里的 `.py` 后，别人拿到的 `芙兰朵露.exe` 还是旧的，这时候才需要重打包：

1. 装依赖（同上）。
2. `pyinstaller` 用 **onedir** 模式（不是 onefile）打 `src\main.py`。
3. 把 `贴图\`、`data\`、`font\`、`sound\`、`model\` 一起放到输出目录里，和 `_internal\` 同目录。
4. 常见坑：图标要用 `贴图\icon.ico`；`font\` 里的思源黑体要一起带上；Qt 插件缺了会直接起不来（PyInstaller 的 PySide6 hook 会自动收集，精简过头就会漏）。

**改 `data\dialogue.json` 和 `贴图\` 里的图片不用打包**，重启 `芙兰朵露.exe` 就生效。

- **发出去的时候别忘了 `LICENSE` 和 `LICENSE-贴图` 两个文件**——GPL-3.0 要求随程序给出许可证和源码（`src\` 随包发布就满足），`LICENSE` 掉了就不合规了。
- 改完记得把 exe 文件名、readme 里的版本号一起更新一下。

### Q4：为什么点她有时候没反应？

**A：** 她在**奔跑**或者**走路**的时候不一定会理你，打盹的时候戳一下倒是会醒。总之跑步不理你那就等她停下来再点。

### Q5：我改了台词 / 贴图，为什么没生效？

**A：** 确认一下有没有完全修改**程序目录下**的文件？确认后**重启程序**即可（这两类文件都不用重新打包）。另外台词文件存成 BOM 编码会静默失效，见 4.2.5。

另外**在线模式开着的时候，点她的台词是现编的**，不会念你写的那些——想听自己写的台词就把在线模式关掉（见 4.2.5 第 5 条）。

### Q6：拖动文件给芙兰后我的文件就消失了！她把我的文件弄哪去了？

**A：** 拖给她的文件是**移动**（不是复制）到程序目录的 `收藏\` 里。移动失败会自动回滚，不会出现"源文件和收藏里各有一份"的情况，具体原因记在 `data\gift.log`。

**所以右键芙兰打开收藏文件夹或者直接去文件目录翻就行了。**

### Q7：她会不会联网、会不会偷看我电脑？

**A：** 分两种情况，全看你开没开那两个开关（都是**默认关闭**的）：

- **默认（离线模式）**：不联网、不收集任何信息。程序里没有任何会自己发出去的请求，数据全存在程序目录里，删掉文件夹就干干净净。
- **开了「在线模式」**：才会连**你自己填的**那个 API 地址，把当前这几句话发过去换成她的回复；同时开了「芙兰看见你在干什么」的话，还会带上**当前窗口标题和程序名**（用来判断你在写东西还是打游戏），**不截图、不碰画面内容**。
- 语音识别用的是程序**自带的本地模型**，按住说话键才录音，录完的临时文件认完字就删，不上传。

两个开关都关掉，就是彻底的离线。

### Q11：二改 / 二传到底怎么算违规？

**A：** 先分清两件事：**代码看 GPL-3.0，贴图看 `LICENSE-贴图`**。实际操作起来是这样：

- 自己改着玩、私下传着玩 → 随便。
- 有偿帮别人改，收手工费 → 可以，包括在约稿平台开设相关业务。
- 把改完的版本**公开发布** → 不用再问我，但要做到：
  1. 保留 `LICENSE` 和原作者署名；
  2. **注明你改了哪里、什么时候改的**（GPL 第 5 条的要求，别嫌烦）；
  3. 你改出来的代码**继续用 GPL-3.0 授权**，并**把源码一起给出去**（打包里 `src\` 就是）；
  4. 贴图如果还是原版，就按 `LICENSE-贴图` 走：非商用、署名、不许单独再分发贴图；
  5. 贴图和台词用了 AI 要说清楚（见 1.3）。
- 把改完的版本**拿去卖**：
  - **贴图全是你自己重画的** → 可以卖，那套图是你的作品（代码部分仍然要开源、给源码）。
  - **贴图还是原版 / 只改了一点** → 不行，`LICENSE-贴图` 不允许拿原版贴图商用。
  - **用 AI 出的贴图去卖** → 不行（见 2.2）。
- 把原版**卖钱** → ~~我砍死你~~（真的不行，尤其别拿原版贴图去卖。）
- 拿 AI 图和 AI 台词糊弄人还卖钱 → ~~同上，见~~ 不行。

> 一句话概括：**代码随便用，只要改完还继续开源给源码；我画的贴图不许拿来赚钱。** 想赚钱就自己画一套。
