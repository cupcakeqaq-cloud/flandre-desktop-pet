## 三、使用说明

### 3.1 语音输入（按住说话键说话）★

**使用前提：接入AI模型并且开启联网功能，识别语音后的回复是完全是依赖于AI文本生成的。**

**这是什么功能？**：按住一个键说一句话，松开之后她把你说的话**在本机认成文字**，显示在气泡里，然后回你一句。

**怎么开**：

1. 右键 →「设置」→ 找到「语音」。
2. 勾上「**按住说话键说话**」，默认说话键是 **F8**。
3. 想修改快捷键：点一下说话键那个输入框，然后按下你想用的键（单个键、或者 `Ctrl+Shift` 这种组合都行，最多三个键），**强烈建议换一个不常用的键**。
4. 取消勾选就是彻底关掉录音功能。

**怎么用**：

- 按住说话键（默认 F8），说话，**说完再松手**。录入文字需要加载一段时间，识别完毕会跳出回答气泡框。
- 按一下马上松手（不到 0.6 秒）算误触，不会触发识别。
- 按住超过 60 秒会自动截断。
- 松开之后最多等 20 秒，还没结果就说一句"没听清"（60 秒内只念一次，不烦你）。
- 录音的临时文件认完字会**立刻删**，不会留在 `data\` 里。

**它到底联不联网、花不花钱**：

- 用的是程序**自带的本机离线识别模型**（在 `model\asr\` 里）。**不联网、不花钱、不上传任何东西。**
  ~~btw程序体积一半来自于这个~~
- ⚠️ **别删 `model\` 文件夹**，删了语音就直接没有。也别在 Windows 隐私设置里关掉"允许桌面应用访问麦克风"。

**语音功能已知问题**：

1. **经常认错字。** 因为是小程序不希望占用太多内存所以牺牲了一下识别准确度orz，但是对话模型差不多都能脑补出来错字原本应该是什么，所以这方面就我已知的情况来看不会很严重的影响对话问题。
2. **什么都没说也可能莫名其妙的识别出语音。**
3. **按住热键没反应，这个非常常见。** 原因基本都是**热键冲突 / 输入法抢键**。作者试图鞭策大肥鱼修了这个问题，但是就目前而言情况还是很严重，需要先点一遍才能顺利触发录音。由于作者编程真的几乎0基础所以解决办法还得慢慢摸索。

### 3.2 在线模式（让芙兰现编台词 / 打字聊天）★

**这是什么**：接一个你自己的大模型 API（OpenAI 兼容的那种），开了之后聊天会变成AI进行角色扮演和你对话：

- **点她一下，她不再从 `data\dialogue.json` 的预设台词里抽，而是现场编一句**（会结合人设和你这会儿在干什么）。
- 右键菜单最上面多一项「**聊天**」，能打字跟她聊。

**所以说只是加了个AI在线角色扮演的功能，不开也完全没事**。

**怎么开（三步）**：

1. 右键 →「设置」→ 找到「对话模型」。
2. 填**接口地址**、**API key**、**模型名**三栏——三样填齐了，"启用在线模式"会**自动勾上**（想回离线就手动取消勾）。
3. 点「**测试连接**」：通了会提示成功；报错的话看下面"出问题先看这里"。

**地址不用写全**，填到域名就行，程序会自动补 `/chat/completions`（末尾多打的 `/` 也能认）：

| 服务                   | 接口地址填这个                         | 模型名填这个                                 | key 去哪弄                                                                       |
| -------------------- | ------------------------------- | -------------------------------------- | ----------------------------------------------------------------------------- |
| **DeepSeek**         | `https://api.deepseek.com`      | `deepseek-chat`                        | `platform.deepseek.com` 注册 →「API keys」→ 新建 → 复制那串 `sk-...`（**只显示一次，丢了就再建一个**） |
| **硅基流动 SiliconFlow** | `https://api.siliconflow.cn/v1` | 网站上那个完整名字，例如 `deepseek-ai/DeepSeek-V3` | `cloud.siliconflow.cn` 注册 →「API 密钥」→ 新建                                       |
| **本机 Ollama**（不花钱）   | `http://127.0.0.1:11434/v1`     | `ollama list` 里看到的那个名字，例如 `qwen2.5:7b` | 本机不用 key，但**这一栏不能空**，随便填一个字（比如 `x`），否则程序当成没填                                  |
| **别的中转站 / 自建**       | 它给你的地址（常见 `https://xxx/v1`）     | 它给你的模型名                                | 它给你的 key                                                                      |

她说的每一句都是一次 API 调用——你点她一下、她自己主动触发的台词和你和她的对话都算一次。

- 她自己凑过来的话有**冷却**（默认 10 分钟才一次）和**每日上限**（默认 **100 条**）。
- 点她 + 她自己说话**合计**每天默认最多 100 次。
- 想省钱：把每日上限调小、或者干脆只在想聊的时候开一下。

**出问题了先看这里**：

1. 「测试连接」通不通？报 **401 / 403** = key 填错了或过期；**402** = 账户余额不够；**429** = 问得太勤，等会儿再试；**其他连不上** = 地址打错了（少了 `/v1`、多了空格、填成网页地址都不行），或者被网络 / 代理挡了。
2. 点她没反应但也不报错 → 每日名额用完了 / 还在冷却，或者上一个请求还没回来。
3. 出错时她会说一句「唉……电波貌似接收失败了，{nickname}去检查一下吧？」，同时 `sound\error.wav` 响一声（60 秒内只响一次，不会连续吵你）。
4. 想在不花钱的情况下试试界面：设置一个环境变量 `FLANDRE_LLM_MOCK=1` 再启动，请求会被假的回复顶掉（**这只是给开发测试用的**，正常玩别设）。

> API key 会**明文**存在 `data\settings.json` 里，就像个记事本；**别把这个文件发给别人**，也别截图发出来。
> 发布包里**不含** `settings.json`，所以别人解压下来是干净的、没有你的 key。

### 3.3 芙兰看见你在干什么（桌面感知）★

__使用前提：同样，这个功能也是依赖于在线模式的AI的，所以使用前务必开启联网以及接入API。__

**这是什么**：她会偶尔瞄一眼你**正在用什么程序**，然后凑过来吐槽一句。

**怎么开**：右键 →「设置」→「芙兰看见你在干什么」→ 勾「**可以主动来搭话**」。

那张卡里还能调：

- **同类冷却**（默认 600 秒）：同一个程序，这么多秒内最多搭一次话。
- **每日上限**（默认 100 条）：跟 3.2 的每日上限是同一本账。

**此功能原理（重点）**：

- **只读窗口标题和程序名**（标题最多截 60 个字），**不截图、不录屏、不看画面内容、不读文件、不碰键盘记录**所以本质上是能保证隐私的。

- 这些文字**只有开了在线模式时**才会跟着请求发给你自己填的那个 API 地址；离线状态下一个字都不外发。

- 采样是后台每隔几秒读一次前台窗口，几乎不占性能。

### 3.8 设置里能改什么

右键 →「设置」：

- **怎么称呼你**：改了之后所有台词里的称呼立刻跟着变（默认是"你"）。
- **气泡时长**：一句话停留几秒。
- **倒计时每秒刷新气泡**：省性能用的开关。
- **界面字体**：切换到系统字体需要重启程序。
- **对话模型（在线模式）**：填接口地址 / API key / 模型名，开了才会现编台词、才有「聊天」。见 3.2。
- **芙兰看见你在干什么**：让她偷偷瞄你在用什么程序（**只读窗口标题和程序名，不截图**），偶尔凑过来说一句；还能设冷却、每日上限、全屏时自动躲起来。见 3.3。
- **语音**：按住说话键说话，松开转成字气泡里显示。认字用的是程序自带的**本机离线模型**，不联网、不花钱。见 3.1。
- **类型管理**：自定义番茄钟的任务类型、倒数日的事件类型（各最多 3 个）。

### 3.9 自带功能一览

- **番茄钟**：可设置专注 / 休息时长、循环次数、长休息，任务类型可自定义。
- **倒计时**：任意时长，到点提醒。
- **倒数日**：设置事件名称 + 类型 + 日期，她会**按类型说不一样的话**（考试、约会、见面、面试、纪念日、生日，或你自己加的类型）。
- **待办清单**：独立窗口，可增删、可勾选完成、双击可改内容；**勾掉的任务不会自动消失**，要清掉得按「清除已完成」（会二次确认）或「删除选中」。
- **整点报时**：每个整点都会报时并随机换一句问候（分凌晨 / 上午 / 午后 / 傍晚 / 深夜）。
- **季节问候**：按春夏秋冬 + 下雨随机插一句问候。
- **赠礼**：拖文件给她 → 收进 `收藏\`，单次拖放总量上限 **100 MiB（约 104.9 MB）**；文件夹也行。
- **在线模式（可选）**：开了之后点她会现编台词、右键能打字聊天。**默认是关的**，不填也没关系，离线该有的功能一个不少。见 3.2。
- **语音输入（可选）**：按住说话键说话，本机认字。**默认是关的**，见 3.1。
- **桌面感知（可选）**：看见你在干什么，偶尔搭一句、催你休息。**默认是关的**，见 3.3。

### 3.10 数据都存在哪

全部在程序自己这个目录里：

| 路径                       | 内容                            |
| ------------------------ | ----------------------------- |
| `data\settings.json`     | 你的设置（称呼、气泡时长、自定义类型、API key……） |
| `data\dialogue.json`     | **全部台词**，可以随便改                |
| `data\chat_history.json` | 在线模式的聊天记录（**每次启动自动清空**）       |
| `data\todos.json`        | 待办列表                          |
| `data\countdown.json`    | 倒数日列表                         |
| `data\gift.log`          | 赠礼拖放的诊断日志（拖文件失败时看这个）          |

> 她只会待在**主显示器**上，多屏的话不会跑去副屏。
>
> 数据不会上传到任何地方。唯一的例外是你自己开了在线模式（见 3.2）/ 桌面感知（见 3.3）：那时候会连**你自己填的** API 地址，把当前这几句对话发过去，感知还会带上窗口标题和程序名（不截图）。

> API key 是**明文**存在 `data\settings.json` 里的（就是个本地文本文件，别把这个文件发给别人）。**发布包里不含 `settings.json`**，所以别人解压下来是干净的、没有你的 key。
> 语音只在**按住说话键的时候**才录音，录出来的临时文件认完字就删了。

**怎么改？**

1. **文件名、目录名、扩展名一个都别改**（程序就是按这些名字去读的），直接**覆盖同名文件**。

### 4.2 台词魔改

#### 4.2.1 台词文件在哪

`data\dialogue.json`——**全部台词都在这一个文件里**，纯文本，用记事本或 VS Code 打开就能改。

结构很简单：**每个分类是一个字符串数组，程序每次从这个数组里随机抽一条。**

```json
{
  "click": [
    "嗯？{nickname}叫我？",
    "干嘛呀。",
    "唔……什么事？"
  ]
}
```

**想加台词就加一行，想删就删掉那一行**（记得保持 JSON 语法正确：字符串之间要有逗号，最后一行后面**不要**逗号）。

#### 4.2.2 分类 → 触发时机对照表

改台词之前先看这张表，找到你想改的那句是"在什么情况下说出来的"：

| 分类                                                                | 什么时候会用到                               |
| ----------------------------------------------------------------- | ------------------------------------- |
| `click`                                                           | 站着的时候被左键点（默认的短应答）                     |
| `click_annoy`                                                     | **3 秒内连点 5 下**，她会生气（同时切 `站立\3.png`）   |
| `idle_talk`                                                       | 主动闲聊（左键时有 25% 概率、以及定时 40~120 秒自己冒一句时） |
| `choices`                                                         | **带选项的对话**（左键时约 15% 概率出现），结构见 4.2.4   |
| `running`                                                         | 开始奔跑时                                 |
| `running_click`                                                   | 奔跑途中被点                                |
| `rest_wake`                                                       | 休息时被戳醒（不满）                            |
| `struggle`                                                        | 被拎起来挣扎时                               |
| `falling`                                                         | 松手后往下掉的时候                             |
| `fallen`                                                          | 摔到地上爬起来时（同时生气脸）                       |
| `drag_down`                                                       | 被拖到任务栏下面（同时生气脸）                       |
| `gift`                                                            | 收到赠礼、成功收下（同时开心脸）                      |

| `countdown_start` / `countdown_end`                               | 倒计时开始 / 归零                            |

| `countdown_day_meet`                                              | 「见面」                                  |

| `todo_done`                                                       | 待办勾选完成                                |
| `hourly_morning` / `_noon` / `_afternoon` / `_evening` / `_night` | 整点报时（按当前时段选）                          |

#### 4.2.3 台词里的三个占位符

| 占位符          | 会替换成                     |
| ------------ | ------------------------ |
| `{nickname}` | 设置里填的**称呼**（默认"你"）       |
| `{name}`     | 倒数日的**事件名称**（只有倒数日的分类能用） |
| `{days}`     | **还剩几天**（只有倒数日的分类能用）     |

例：`"{nickname}，考试还有{days}天，别慌哦。"`

> **硬规则：台词里不要写死"你"**，称呼一律写 `{nickname}`。
> 否则改了称呼之后，那句话还是喊"你"，会很出戏。

#### 4.2.4 选项对话（`choices`）怎么写

`choices` 是数组里套对象，每条长这样：

```json
{
  "line": "唔……好无聊！我们一起玩呀？",
  "options": [
    { "label": "好啊，玩什么？", "reply": "诶嘿嘿！{nickname}猜……算了，我自己也忘了。" },
    { "label": "等一下，我在忙", "reply": "唔……那{nickname}忙吧，快点哦。", "mood": "angry" }
  ]
}
```

- `line`：她问的那句话。
- `options`：按钮，2~3 个都行。
- `label`：按钮上的字。
- `reply`：**你选了这个之后她的反应**（就是"改触发反应"最直接的地方——想让她在被拒绝时说的话变温柔一点，改 `reply` 就行）。
- `mood`（可省略）：选完后她的表情。
  - `"mood": "angry"` → 生气脸（`站立\3.png`）
  - `"mood": "happy"` → 开心脸（`站立\4.png`）
  - **不写** → 普通表情
  - 表情只在站着的时候生效，持续时间和气泡一样长。

#### 4.2.5 改台词的注意事项

1. **编码必须是 UTF-8，而且千万不要存成"UTF-8 with BOM"**。带 BOM 会让程序读不出台词文件（而且不会报错，所以要特别注意）。记事本另存为时注意选「UTF-8」而不是「UTF-8 with BOM」。
2. **JSON 语法要正确**：字符串用双引号、条目之间用逗号、最后一条**不能**有逗号。写完丢进任意在线 JSON 校验器点一下最稳。
3. **改完不用重新打包**，重启 `芙兰朵露.exe` 就生效。
4. 别删掉整个分类。真的删了程序只是在那句话该出现的时候找不到内容，触发对话时会沉默。
5. **在线模式下 `click` 这些离线台词就不走了**（她改成现编）；想让她继续念你写的台词，就关掉在线模式。

### 4.3 改角色名字（人物魔改）

名字不是设置项，而是写在程序里的，一共 4 处：

| 位置                   | 是什么                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------- |
| `src\config.py:4`    | `APP_NAME = "芙兰朵露"`——托盘图标的悬停提示（`src\tray.py:14`）和程序内部名（`src\main.py:44`）都读它           |
| `src\bubble.py:42`   | `QLabel("芙兰朵露·斯卡蕾特")`——对话气泡顶上那行标题。**注意代码里写的是"斯卡蕾特"，和 readme 正文用的"斯卡雷特"不一样，改的时候别改错地方** |
| `data\dialogue.json` | 台词里直接喊到自己名字的句子（搜「芙兰」「芙兰朵露」），属于台词内容，只能一句句手动改                                           |
| 文件名                  | `芙兰朵露.exe`、`贴图\icon.ico`（托盘图标），想换就一起换                                                 |

### 4.4 改代码 / 重新打包

- 源码在 `src\` 里（Python 3.12 + PySide6 + Pillow，用 PyInstaller 按 onedir 方式打包）。
- **改 `.py` 文件必须重新打包才能生效**；改 `data\dialogue.json` 和 `贴图\` 里的图片则不用，重启程序就行。
- 打包大致流程：装好依赖 → `pyinstaller` 用 onedir 模式打 `src\main.py` → 把 `贴图\`、`data\`、`font\`、`sound\` 一起放到输出目录里 → 打包出来的 exe 必须和 `_internal\` 同目录。
- 只改了 `src\` 里的 `.py`、没加新依赖的话，有更省事的办法（不用跑上面整套）：`.venv\Scripts\python.exe 工具\repack.py --smoke`，几秒钟把新代码换进 `芙兰朵露.exe` 并自动启动验证一次。原理和注意事项见 `交接文档.md` 的 §4.6。
- 常见坑：图标要用 `贴图\icon.ico`；`font\` 里的思源黑体要用上就得一起带上；Qt 插件缺了会直接起不来（PyInstaller 的 PySide6 hook 会自动收集，但精简过头就会漏）。
- **发出去的时候别忘了 `LICENSE` 和 `LICENSE-贴图` 两个文件**——GPL-3.0 要求随程序给出许可证和源码，`LICENSE` 掉了就不合规了。
- 改完记得把 exe 文件名、readme 里的版本号一起更新一下。

**最后只是一些制作心得和碎碎念，单纯只是想玩桌宠的可以完全不看：**



进行了一个或许没什么必要的版本更新，主要还是追加了在线聊天的功能，因为之前的版本感觉互动感太弱了。



说实话，虽然做的是芙兰朵露的同人程序，但是本质上我希望的是做一个“能随便修改”的桌宠，也就是说随便魔改成什么角色都行，或许可以说我只是在实现这个想法的时候使用了二小姐这个角色（至于为什么角色是芙兰朵露，单纯是因为喜欢这个角色所以选择了她）
当然肯定已经有人做过这种东西并且开源了，但是迄今为止见到的大部分都是固定在一个位置的Live2D或者3D模型的桌宠（也有可能是信息茧房导致我没见过），所以我希望能有个互动感更强的桌宠。至于为什么没用Live2D——单纯只是因为我不会做，感觉k帧比多画几张贴图更麻烦干脆还是做成这种PPT了，所以在角色的灵动感上肯定不如Live2D，但是这个方法是我的舒适区。
至于灵感来源的话，有一部分来自于以前很流行的QQ宠物，还有一部分是小时候看到的各种会在电脑里爬来爬去的古早桌宠。说实话我也不清楚我现在做的这个是不是在重复造轮子，是的话就只当我是一个脑子不好用的笨蛋吧......

以及我自认为从上面的使用规则就能看出来一件事：**我很抵触AI生图，也不认为使用AI工具做出来的东西能完全算作是使用者的作品。**
事实确实如此，我本质上其实只是个小画师，并不是什么程序员，所以关于我对AI生图技术的态度大伙应该是可以猜个大概的。
**然而我并不否认AI技术的便捷性**，对于不会画画的人来说AI生图确实能填补自己不会画画的短板，就像我想做出这个程序但是对代码一窍不通一样，AI工具的便捷象征的也是时代和技术的进步。
但是AI生图技术必然逃不开模型训练无授权盗用人类画师的作品进行“炼丹”这个争议点，所以作为画师的我永远无法接受“AI图也有著作权，我可以把AI图说成是自己的作品”这个说法。因此我真的真的非常不希望有人在魔改此程序贴图时使用AI后不明确标注并且进行商用，**不过换言之，你不把我的贴图拿去当生图原型并且好好标注该标注的东西那么免费发布完全没问题。**
所以这归根结底只是立场问题，你真的这么做我也阻止不了你。

最后感谢你能看到我这段碎碎念，此程序归根结底只是兴趣使然的产物，~~有的时候甚至还在焦虑发了一坨代码全是AI生成的程序会不会被骂~~，人菜瘾大，很多东西都不会，所以如果真的有大佬看到还请多多海涵orz。



感谢看到这里的你，可能下次更新这里还会写一堆小作文。
